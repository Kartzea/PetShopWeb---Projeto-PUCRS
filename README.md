# PetShopWeb

Site desenvolvido como projeto acadêmico para a disciplina de Desenvolvimento Web.

## Navegação do site

O site possui três páginas principais:

**Página Inicial (`index.html`):** apresenta o pet shop e suas informações gerais.

**Produtos (`produtos.html`):** apresenta os produtos disponíveis, organizados em três categorias: acessórios, rações e higiene e limpeza.

**Serviços (`servicos.html`):** apresenta os serviços de banho e tosa, com informações sobre valores e disponibilidade de tele-busca.

## Como navegar

Utilize o menu de navegação localizado no cabeçalho do site para acessar as três páginas.
